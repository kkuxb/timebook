# 原型源码

这些 `.dc.html` 文件是在 Claude 设计画布里制作的交互原型，依赖画布运行时（`support.js`），不能直接用浏览器打开。

开发时可以参考其中的：

- `<style>` 里的样式类（`.card`、`.btn`、`.primary`、`.gap` 等）和数值
- `renderVals()` 里的交互逻辑：空档计算、补记录弹窗、日历拖动、统计汇总、标签删除迁移

| 文件 | 页面 |
| --- | --- |
| `Today.dc.html` | 今日：待办、专注计时、时间线与补记录、数据同步状态 |
| `Calendar.dc.html` | 日历：周视图、拖动补记录、点击编辑 |
| `Stats.dc.html` | 统计：日 / 周 / 月 / 年，模块 / 事项，趋势 |
| `Tags.dc.html` | 标签：模块与事项的增删改，删除时迁移记录 |

注意：原型为了演示做了简化，开发以 `docs/开发方案.md` 的规则为准，例如跨天记录的统计口径、"现在"时间固定为 17:20 起算、11.13 之前为生成的示例数据。
