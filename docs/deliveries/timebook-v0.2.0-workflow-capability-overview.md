# 时间簿（Timebook）v0.2.0 工作流程与能力总览

- **一句话定位**：在 `v0.1.0` 全栈与轻量桌面版基础上，新增支持三千条级检索、列表行内轻点直改与百条批量整理的 **「历史」模块**，升级 **「今日」`8–24` 点自适应时间横条**，根治 **灵动胶囊开始计时延迟**，并干净下线已完成历史使命的 `Notion` 导入模块。
- **适用范围**：`Windows 10/11` 轻量桌面版（单机或连 `NAS`）、桌面网页端、手机 `PWA` 与绿联 `NAS` 容器版。

## 二、日常核心能力与交互流程对照

| 模块 / 动作 | 你在界面上怎么操作 | 系统底层做什么（全部本地/自托管确定性执行，`0` 大模型消耗） | 你感知到的结果 |
| --- | --- | --- | --- |
| **1. 检索与查看全量历史记录** | 点主导航中间的 **「历史」**（默认展示「全部时间」），点选 `今日 / 昨日 / 本周 / 上周 / 本月 / 上月 / 自选范围`、选择一级模块或二级事项（或「未分类」）、或在搜索框输入关键词 | 按北京时间自然周期与区间交集毫秒级过滤已结束记录（3,750 条实测 `25–47 ms`），跨零点记录保持单行完整呈现，默认按开始时间倒序每页渲染 50 条 | 顶部胶囊实时算出命中总条数与累计总时长；三千多条记录秒切不卡顿 |
| **2. 历史列表行内轻点直改** | 在「历史」列表任意一行：直接点 **彩色标签胶囊**、点 **标题文字**、或点 **起止时间** | 胶囊弹出轻量分组面板一点即存；标题变单行输入框回车即存；时间展开日期与起止时刻条（自动识别跨次日）保存后实时重算时长 | 不用频繁开关大弹窗，随手点一下就能改完标签、标题或时间 |
| **3. 多选与跨页全选批量整理** | 勾选多行（支持 `Shift` 连选，或勾选本页后点顶部横条 **「全选当前筛选出的全部 N 条记录」**），使用底部黑色批量栏 | 将选中记录的修改合并为 **单次内存更新 + 单次数据库批写入 + 单批次同步**（130 条批量改标签实测 `190.5 ms`） | 一键完成 **批量改标签**、**批量改标题（留空可清空独立标题）** 或 **批量软删除**（误删 30 天内可在设置回收站恢复） |
| **4. 灵动胶囊零延迟开始专注** | 在主窗口、快捷键呼出框（`Ctrl+Alt+T`）或系统托盘菜单点开始专注 | 乐观状态更新后第 `1` 毫秒直接把进行中列表推给灵动胶囊并立即对齐毫秒时钟；同时修复每日备份逻辑（同日仅首次写备份文件，不再每次重复全量拷贝） | 实测真机胶囊在 **`4–11 ms`** 内瞬间切换运行态并准确跳秒，彻底消除卡顿与首秒假死 |
| **5. 今日页自适应起点时间横条** | 打开 **「今日」** 页面查看或切换日期 | 当天无 8 点前记录时默认采用 `8–24` 点（16 小时）刻度；若有 `6–8` 点早起记录自动展至 `6–24` 点；若有 `0–6` 点凌晨加班记录自动展至 `0–24` 点并铺浅灰斜纹区分 | 平时砍掉三分之一睡眠空白，白天色块和 20 分钟空档放大 `50%`；熬夜加班日自动完整展现不丢记录 |
| **6. 纯净数据导出与备份管理** | 打开右上角齿轮 **「设置与数据」** | 已彻底移除 `Notion` 导入卡片、接口与解析包；保留原有 `source="import"` 存量数据读取、全量 `JSON`/`CSV` 导出、每日自动备份与回收站 | 设置界面清爽聚焦，已导入的三千七百多条历史记录 `100%` 零损保留 |

## 四、能做 / 不做边界与 PM 提请留意的细节

- **能力边界**：
  - **能做**：全量已结束记录检索、单行原地快改、跨页全选百条级批量修改与软删恢复、单机免配直用、双击覆盖安装平滑升级、随时转连绿联 `NAS` 多端同步。
  - **不做**：「历史」列表不混入正在跑秒表的进行中记录（进行中计时统一在「今日」页与灵动胶囊结束或管理）；不再支持上传导入新的 `Notion CSV`。
- **已知测试边界与两项极轻微非阻断细节（供决策直接收口或顺手微调）**：
  1. 隔离无头测试中未人工物理点击系统托盘右键菜单与物理按键，你覆盖安装后可顺手按一下 `Ctrl+Alt+T` 与托盘菜单体验；
  2. 两处细微非阻断观察点：① 历史列表行内展开改时间时，左下角「次日 · 1 h 45 min」小提示在窄列下会折成两三行（不影响保存与功能）；② 网页模式（非桌面单机模式）下载 `CSV` 时经文本流转换去掉了文件头 `BOM` 字节（`UTF-8` 内容完整无损，桌面单机模式导出已带 `BOM`）。这两项均不阻断正常使用。
