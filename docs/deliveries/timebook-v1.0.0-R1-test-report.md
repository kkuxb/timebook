### 问题清单与最小修复要求

#### 1. 必须修复（阻断收口）
1. **`DEF-A5-01`（高 / Major）— Notion 导入「整批撤销」未撤销同批导入的待办（`todos`）且未回滚本批新建事项标签（`tags`）**
   - **实测证据**：`A5-run1/result.json`、`A5-run1/a5-after-undo.png`、`A5-run1/data/timebook.sqlite`。导入 6 条专注记录、2 条未完成待办与 14 个事项标签后点击「整批撤销」，`sessions` 已软删除且统计清零，但 2 条待办（`编写Timebook盲测报告`、`周末健身计划`）在 `SQLite` `todos` 表（`deleted_at=null`）、`IndexedDB`（`active=2`）与待办页面刷新后依然残留，14 个本批次新建 `tags` 亦未撤销。
   - **定位线索**：`apps/api/src/db/client.ts` 与 `schema.ts` 中 `todos` 表缺少 `import_batch` 字段；`apps/api/src/import-export.ts` 的 `undoImportBatch()` 仅查询并软删除 `sessions`。
   - **最小修复与验证标准**：
     - 为 `todos` 表（以及按需对本批次新建 `tags` 或记录新建 `tagIds` 元数据）关联 `import_batch`（存量空库或升级兼容 `ALTER TABLE` 补列）；
     - `undoImportBatch` 在同一事务中一并软删除同 `import_batch` 的 `todos`，且对本批次新建的 `tags` 在确认未关联非本批次活跃数据时一并软删除；
     - 补充集成单测并在 `A5` 复测中验证撤销后 `sessions`、`todos`、本批独占 `tags` 在数据库、`IndexedDB` 与页面刷新后均干净移除。

2. **`DEF-A3-01`（中 / Major）— 删除空模块/空事项前端传 `targetModuleId: ""` 触发服务端 `400` 且前端假同步**
   - **实测证据**：`A3-run1/result.json`。在标签页删除新建空模块时，前端向 `POST /api/mutations` 发送 `type: "module.delete"`, `payload: { id, mode: "drop", targetModuleId: "" }`，被服务端 Zod 校验 `min(1)` 拒绝返回 `400`；前端页面却移除了该模块且胶囊仍显示「数据已同步」，数据库 `deleted_at` 仍为 `null`。
   - **定位线索**：`apps/web/src/components/TagDeleteModal.tsx`（第 78–88 行）在 `!hasData` 走 `'drop'` 分支时，仍判断 `effectiveMode === 'move' ? targetId : undefined`（因 `mode` 状态默认 `'move'` 且 `targetId === ''`），把空字符串传入 `deleteModule`/`deleteTag`；同时 `apps/web/src/store/useAppStore.ts`（第 364–375 行）收到 `400/409` 丢弃队列批次后未触发回滚拉取。
   - **最小修复与验证标准**：
     - 删除空模块/空事项时，仅当实际执行 `'move'`（`hasData && effectiveMode === 'move'`）且 `targetId` 非空时传入目标 ID，否则严格传 `undefined`；
     - 在 `useAppStore.ts` 中若服务端因 `400/409` 拒绝某批 mutation，应触发重新全量/增量拉取还原真实服务端状态或显式展示告警状态，严禁静默留存失真乐观视图；
     - 复测 `A3` 删除空模块与空事项，确认 `/api/mutations` 返回 `200` 且 `SQLite` `deleted_at` 非空。

3. **`DEF-A6-01`（中 / Minor-Usability）— 手机视口（`390×844`）日历页默认「3 天」视图初始窗口未包含「今天」**
   - **实测证据**：`A6-run1/a6-mobile-calendar.png`。周四 `2026-11-19` 在 `390×844` 视口打开「日历」页，默认进入「3 天」模式，但日期栏显示 `11.16 – 11.18`（周一至周三），当天 `11.19` 不在默认视野内。
   - **定位线索**：`apps/web/src/pages/CalendarPage.tsx` 初始 `anchorStart` 设为 `getWeekStart(todayStr)`（周一），手机 3 天视图 `visibleStart` 未在初始化或切换至 3 天模式时将窗口定位到包含 `todayStr`。
   - **最小修复与验证标准**：手机端首次进入日历页（或重置到当前周期）的默认「3 天」窗口须确保包含 `todayStr`（例如 `[今天-2, 今天-1, 今天]` 或 `[昨天, 今天, 明天]`），周四～周日均可直接看到当天列；且点「今天」与切换「单日」保持正常。
