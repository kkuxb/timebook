# 时间簿（Timebook）v1.0.0 工作流程与能力总览

- **依据版本与实物**：独立发布包 `workspace-data/outputs/timebook/v1.0.0-R2/timebook.zip`（84 个源码与配置文件，`SHA-256: aec7b90a88c10cc4fa497ccb549ef16c2ce1b9a5d591394fda5f3debddee8dbe`）及 `R1`、`R2` 两轮真实浏览器与数据库测试产物。
- **一句话定位**：专为个人单用户打造的私密时间记录、多周期可视化统计与待办管理全栈应用（单容器部署在绿联 `NAS`，替代原 `Notion`「个人时间可视化管理」工作区，全程零大模型调用、断网不丢数据、多设备自动同步）。

---

## 一、整体运作示意

```
手机（全屏 PWA） / 电脑浏览器
   │  ① 操作即时写入本机 IndexedDB 暂存队列（秒级响应，断网也能记）
   ▼
后台增量同步与幂等接口（/api/mutations + /api/sync）
   │  ② 网络通畅时自动补传，重复重放自动去重，右上角实时展示四态胶囊
   ▼
绿联 NAS 本地持久化存储（/volume1/docker/timebook/data）
   ├─ timebook.sqlite（WAL 模式单文件数据库，健康检查每 30 秒真实读写校验）
   └─ backups/（每天凌晨 03:00 自动在线热备 .sqlite 留存 30 份 + 每周一全量 .json）
```

## 三、一次性准备（上线只需做一次）

1. **在绿联 `NAS` 启动容器**：按 [绿联 NAS 部署指南](../绿联NAS部署指南.md) 新建 `/volume1/docker/timebook/data` 目录，在「`Docker` → 项目」填入自己的访问口令启动；空库首次启动会自动建好 **工作、学习、游戏、锻炼** 四个默认模块。
2. **导入 `Notion` 历史数据（可选）**：在 `Notion` 导出 CSV 后，点右上角齿轮「设置」→「选择 CSV 文件」，核对预览卡片上的总条数与各模块累计时长，一键处理问题行后点「确认导入」。如果不满意，下方随时可点「整批撤销」一键清空当次导入的记录、待办和新建事项标签。
3. **手机添加到主屏幕（可选）**：开启 `Tailscale HTTPS` 后，在手机浏览器打开专属地址点「添加到主屏幕」，即可作为全屏独立应用使用。

## 四、日常使用流程与机制（全部确定性程序执行，零 AI 参与）

| 日常动作 | 系统后台做什么 | 你在界面上看到什么 |
| --- | --- | --- |
| **随时开始专注** | 立即在本机与服务端创建未结束记录（支持多条同时计时） | 今日页专注区出现对应模块浅色卡片，数字每秒跳动，顶部模块今日用时同步增长；手机端底部浮现黑色迷你计时条。 |
| **从待办点「开始这件事」** | 自动带上该待办的事项标签、关联关系和标题开始计时 | 不用再弹标签选择框，计时结束后时长自动算进该待办的「已投入」时间。 |
| **补上漏记的空档** | 合并当天所有时间段，找出相邻两段之间 `>= 20 分钟` 的空白 | 时间线只把满 20 分钟的中间空白标成橙色斜纹块（15 分钟小间隔、第一条前、当前时刻之后绝不误报）；点「+ 补上」自动填好起止时间，也可以在日历页按住鼠标往下拖拽 15 分钟一格补录。 |
| **管理今日与未来待办** | 按计划日与重复规则（每天/每周几/每月几号）实时过滤，错过轮次不堆积 | 顶部输入框回车秒建今日待办；切换「今日 / 全部未完成」可查看未来待办；点击卡片可改截止倒计时、重复规则或删除。 |
| **跨零点熬夜记录与看统计** | 按北京时间 `00:00` 将跨夜记录精确切分到前后两天；统计页与日历页仅纳入已结束记录 | 比如前一天 `23:00` 到当天 `01:30`：前一天统计分得 `1h`，当天分得 `1.5h`；但在看整周统计时，「专注次数」自动去重只算 `1 次`。 |
| **删改标签或误删反悔** | 软删除保留 30 天；删标签时支持「迁移」或「连同记录删除但保留待办」 | 选「连同记录一起删除」时，关联的未完成待办不会被误删，而是安全转为「未分类」；30 天内随时可在「设置 → 回收站」一键恢复。 |
| **地铁断网或重启 NAS** | 本地 `IndexedDB` 暂存所有改动并按 `2s → 5s → 15s → 30s` 自动重试 | 界面操作依然秒开秒改，右上角变成橙色「连接断开 · N 条待保存」，网络一通几秒内自动补传变回绿色「数据已同步」。 |

## 五、实测真实例子（来自隔离测试库与导出结果）

1. **`Notion` 标题智能保留与去重（场景 `A5` 实测导出 CSV）**：
   - 导入标签为 `单机游戏`、`日历标题` 为 `影之刃零` 的记录 → 时间线显示 **「单机游戏 · 影之刃零」**，导出 CSV `具体内容` 列为 `影之刃零`；
   - 导入标签为 `原神`、`日历标题` 同为 `原神` 的记录 → 时间线干净显示 **「原神」**（不累赘显示「原神 · 原神」），导出 CSV `具体内容` 列自动留空。
2. **跨零点 + 重叠并行 + 进行中隔离（场景 `A4` 实测）**：
   - 同时放入：周三 `23:00`–周四 `01:30`（2.5h）、周四 `05:00–05:40`（40m）、周四 `10:00–11:00` 工作 1h + 游戏 1h 重叠、外加 1 条正在运行的「锻炼」计时；
   - **今日页**实时计入进行中的「锻炼」；**日历页与统计页**严格隐藏进行中计时，周四列顶部显示 `06:00 前 · 2 条`，本周统计精准得出总时长 `5 h 10 min`、日均 `1 h 18 min`（按本周已过 4 天折算）、专注次数 `4 次`。

## 六、能做什么 / 本版不做什么

- **能做**：口令登录（180 天免重登 + 连续输错 5 次防爆破锁定）、多计时并行、空档检测与拖拽补录、可选具体内容标题、一次性与重复待办全套管理、四周期×双维度可视化图表、两级标签 8 套配色与安全删除迁移、真实 `Notion` 三表导入对账与整批撤销、`JSON/CSV` 导出、30 天回收站、每日自动热备、电脑与手机 `PWA` 自适应同步。
- **本版不做（已确认边界）**：多用户账号体系、番茄钟与白噪音、手动归档按钮、长篇备注字段、忘关计时推送提醒、每隔 N 天/法定节假日等复杂重复规则、手机端日历长按拖拽（手机端直接点顶部「+ 补记录」按钮）、桌面原生悬浮小窗（留作后续可选扩展）。

## 七、实测时长与 Token 消耗

- **应用日常运行**：**`0 Token`、`0` 次大模型调用**；5,000 条记录规模下统计与空档纯函数计算耗时远低于 `20 毫秒`。
- **研发与独立盲测消耗（共 2 轮收敛，上限 3 轮）**：
  - 第 1 轮（`R1`）：全量跑完 14 项确定性测试 + `A1`–`A6` 六个独立盲测场景（单场景耗时 `153 秒`～`624 秒`，均在 `900 秒` 硬上限内），检出 3 项边界问题（整批撤销漏待办/标签、删空模块参数报错、手机日历 3 天默认窗口未含今天）。
  - 第 2 轮（`R2`）：定向修复并重跑 `A3`、`A5`、`A6`（耗时 `612 秒`、`304 秒`、`252 秒`），全部 100% 达标归零。

## 八、与原始方案的对照及建议你重点关注的点

1. **三处贴合真实数据的体验增强（均已按 `C-01`～`C-06` 落实）**：
   - `Notion` 导入优先读取 `日历标题` 列（保住你原来记在标题里的项目名与游戏名），并兼容没有标签列的 `待办.csv`；
   - 待办区补齐了点击卡片完整编辑弹窗与「今日 / 全部未完成」切换器，管理未来待办不再受阻；
   - 登录 `Cookie` 支持协议自适应（在家里先用 `http://<NAS局域网IP>:3210` 就能直接登录验收，配好 `Tailscale HTTPS` 后自动升级安全标记装手机 `PWA`）。
2. **建议你验收时重点确认**：
   - 当前所有本地功能、数据闭环与视觉还原均已通过验证；**唯一尚未实机运行的是在你家的绿联 `DXP4800 Plus` 上真实启动容器与导入你自己的全量 `Notion` 导出包**。确认本版收口归档后，即可直接按指南（或由我协助）上线实测。
