- **依据版本与实物**：
  - 独立源码发布包：`workspace-data/outputs/timebook/v1.1.0-R4/timebook.zip`（121 个源码与配置文件，`SHA-256: 49d2fecaf9dd75fb0415b61a43d21d959993ab98a9d314b30ccaa68db01ba9b4`）
  - 实编桌面安装程序：`workspace-data/outputs/timebook/v1.1.0-R4/installers/时间簿_1.1.0_x64-setup.exe`（约 `2.15 MiB`，`SHA-256: 46e769d8dd863531b3f96a6f7102389a053f54e3fb1a2914b8cc36dc0584bd6f`）与单文件便携版 `timebook-desktop.exe`（约 `9.47 MiB`）

- **一句话定位**：专为 `Windows 10/11` 打造的超轻量个人时间管理桌面客户端——**无需部署服务器即可单机开箱直用（自带本机双保险文件防丢备份）**，日常提供置顶灵动胶囊、右下角托盘秒开与全局快捷键呼出，日后部署好家庭绿联 `NAS` 时可一键无损合并全部单机历史数据。

## 一、双模式整体运作示意

```text
【阶段一：未部署 NAS · 电脑单机直用模式（默认）】
Windows 桌面四部件（主窗口 / 置顶灵动胶囊 / 右下角托盘 / Ctrl+Alt+T 呼出框）
   │  ① 免口令秒进主页，多窗口通过内存总线毫秒级同步（实测 18~67ms）
   ▼
双重本地防丢存储（不怕清理浏览器缓存）
   ├─ 实时原子文件：%APPDATA%/com.timebook.desktop/timebook-local.json
   └─ 每日自动快照：文档/TimebookBackups/timebook-local-YYYY-MM-DD.json（自动留存最近 30 份）

             │
             │  ② 日后绿联 NAS 部署就绪 → 在桌面设置填入地址与口令点「连接并同步」
             ▼

【阶段二：连接绿联 NAS · 多设备实时同步模式】
智能无损合并引擎（planLocalToRemoteMerge）
   ├─ 同名默认四模块（工作/学习/游戏/锻炼）自动对齐复用，绝不产生重复模块
   └─ 单机积攒的新模块、事项、专注记录（含进行中）与待办 100% 幂等上传至 NAS SQLite
   ▼
电脑桌面端 ⇄ 绿联 NAS 容器 ⇄ 手机全屏 PWA（断网橙色暂存，联网自动补传）
```

## 三、一次性安装与上手（只需 1 分钟）

1. **安装或直接运行**：双击 `时间簿_1.1.0_x64-setup.exe` 按向导安装（或直接把 `timebook-desktop.exe` 放到常用目录双击运行）。
2. **开箱直用无需配置**：首次打开直接进入「今日」视图，右上角显示青绿色 **「本机已保存 · 单机模式」**，已自动准备好「工作、学习、游戏、锻炼」四个默认模块（也可以在右上角设置抽屉直接导入之前的 `Notion` 导出 `CSV`）。
3. **按喜好调整桌面习惯（可选）**：点右上角齿轮「设置」，可一键开启「开机自动启动」、切换悬浮胶囊小窗的「白底干净 / 墨色深底」外观、开启「无进行中计时时自动隐藏小窗」或修改本地自动备份文件夹。

## 四、日常四大桌面部件工作流（全部本地确定性执行，零 AI 消耗）

| 桌面部件 | 怎么触发 / 操作 | 系统后台做什么 | 你在电脑上看到什么 |
| --- | --- | --- | --- |
| **1. 置顶灵动胶囊小窗** | 平时常驻屏幕角落（可自由拖拽记忆位置）；鼠标移入自动展开 | 实时订阅专注计时变化，动态伸缩窗口尺寸 | 平时只露一条窄胶囊（呼吸色点 + 事项名 + `+N` 多任务徽标 + 等宽跳秒），不挡办公文档；鼠标移上去丝滑展开全部进行中计时与一键 **「结束」「+ 新建专注」「主界面」**，移开鼠标自动收回。 |
| **2. 右下角系统托盘** | 左键点图标唤回主窗；右键点图标打开快捷菜单 | 每次数据变更实时提取最近使用过的前 5 个未删除事项更新原生菜单 | 右键菜单直接显示当前进行中条数，无需打开任何窗口即可点 **「一键开始最近常用事项」** 秒开计时，或点 **「结束全部进行中计时」**。 |
| **3. 全局快捷键呼出框** | 在任意软件里按下 `Ctrl + Alt + T`（可在设置改键） | 屏幕正上方置顶唤起极简框并自动聚焦输入框 | 直接打字输入正在做的具体内容、点选事项标签（或直接按 `Enter` 回车），立刻开始计时并自动收起窗口把焦点还给原软件；按 `Esc` 干净取消不留脏记录。 |
| **4. 无边框主窗口** | 查看完整四视图（今日/日历/统计/标签）；点右上角 `×` | 默认隐藏主窗口至右下角托盘，保持后台进程与小窗常驻 | 点 `×` 不会误关正在运行的计时；所有改动实时双写本机文件并更新当日备份快照。 |

## 五、实测验证过的真实例子（来自独立盲测证据）

1. **多窗口冷启动防重与清缓存无损恢复（场景 `D1` 实测）**：
   - 全新目录启动 `timebook-desktop.exe`（主窗口、胶囊小窗、呼出框三窗同时加载），`timebook-local.json` 与 `backups/` 快照中严格只生成唯一的 **4 个默认模块**；
   - 新建事项、专注记录与待办后，即使把内置浏览器的 `IndexedDB` 数据库彻底清空再重新打开，数据仍从本机 `timebook-local.json` **100% 自动无损恢复**。
2. **灵动胶囊小窗双皮肤与毫秒级多窗联动（场景 `D3` 实测）**：
   - 同时开启「编码实现」与「阅读学习」两条计时，小窗紧凑态显示 `编码实现 +1 00:00:01`；悬停展开点击「结束」后，主窗口在 **`17.8 ms`～`67.4 ms`** 内实时同步结束并计入今日时间线；切换「墨色深底」后深灰底配亮白字与明黄按钮对比清晰。
3. **单机攒数据后首次接入 `NAS` 智能去重合并（场景 `D6` 实测）**：
   - 先在单机模式于默认「工作」模块下记 2 条记录 + 1 条待办，再新建「阅读」模块记 1 条记录（共 100 分钟）；随后连接全新的 `@timebook/api` 服务（自身也带默认四模块）；
   - 连接同步后，服务端模块总数精准为 **5 个**（工作、学习、游戏、锻炼、阅读，**未出现两个「工作」模块**），3 条记录与待办分秒不差落入服务端 `SQLite`；模拟断网再记 1 条时右上角切为橙色「连接断开 · 1 条待保存」，服务恢复后自动补传为 4 条（共 120 分钟）。

## 六、能做什么 / 本版不做什么

- **能做**：`v1.0.0` 全部四视图统计与 `Notion` 导入导出能力 + 单机免配直用 + 本机双保险自动备份（留存 30 份）+ 单机转连 `NAS` 无损去重合并 + 定制无边框主窗关窗缩托盘 + 置顶灵动胶囊小窗（悬停展开、白底/墨底切换、空闲自动隐藏）+ 托盘右键一键开始最近 5 个常用事项 + `Ctrl+Alt+T` 全局极速呼出框 + 开机自启开关 + `2.15 MiB` 超轻量安装包。
- **本版不做（已确认边界）**：`macOS` / `Linux` 实机安装包测试、`Windows 11` 系统小组件面板集成、多用户人工冲突合并器、付费代码签名证书（个人自用首次安装若遇系统蓝框提示点「更多信息 → 仍要运行」即可）。

## 七、实测指标与研发轮次消耗

- **桌面程序日常运行消耗**：**`0 Token`**（零外部大模型请求）；安装包实编体积 **`2.15 MiB`**（远优于 `<= 15 MB` 目标）；多窗同步延迟 **`17.8 ms`～`67.4 ms`**（优于 `< 200 ms` 上限）。
- **研发与独立盲测轮次（共 3 轮收敛，符合最多 3 轮预算）**：
  - `R1` 完成全栈开发打包与 `D1`–`D6` 首轮盲测（`D2`/`D3`/`D4`/`D6` 一次通过，拦截真实多窗冷启动重复生成默认模块问题 `D1-DEF-01`）；
  - `R2` 关闭 `D1-DEF-01`，复测中进一步拦截呼出框鼠标点选标签按钮后直接按 `Enter` 焦点未提交细节 `D5-DEFECT-1`；
  - `R3` 定向修复并通过 `D5` 真实键鼠流盲测（单场景耗时 `195 秒`），`20/20` 前端与接口单测 + `4/4` 原生单测 + `D1`–`D6` 全量通过。

## 八、与确认需求逐条对照及建议重点体验点

- **与 `C-08`～`C-12` 对照**：双模式切换与单机防丢备份（`C-08`/`C-11`）、本机实编安装包与云端打包配置（`C-09`）、灵动胶囊小窗形态 + 白底/墨底切换 + 四大桌面部件（`C-10`）均已 100% 按确认口径落地，无功能删减。
- **建议你本机双击试用时重点感受的 3 个点**：
  1. **灵动胶囊小窗手感**：把鼠标移入/移出小窗感受展开收起尺寸与白底/墨色深底在日常壁纸和文档上的观感；
