# 时间簿（Timebook）Windows 桌面版使用说明

欢迎使用**时间簿 Windows 轻量桌面版（`v0.2.1`）**。本软件无需事先购买服务器或部署后端，双击即可直接记录时间、检索整理历史记录、查看图表统计与管理待办；未来部署好家庭 NAS 或 Docker 服务后，也可一键将单机积累的全部历史记录无缝合并同步到多台设备。

---

## 一、安装、覆盖升级与单机零配置开始

1. **安装或覆盖升级**：
   - **安装版（推荐）**：双击 `Timebook_0.2.1_x64-setup.exe`（或本地编译生成的 `时间簿_0.2.1_x64-setup.exe`），按中文向导提示完成安装；安装包体积约 `2.2 MB`，基于 Windows 系统自带的 `WebView2` 运行，内存占用轻巧。
   - **旧版无缝覆盖升级**：已安装旧版（如 `v0.1.0`、`v0.2.0`）的用户直接双击新版 `-setup.exe` 覆盖安装即可（若此前曾安装早期 `1.1.0` 内测包、安装向导提示检测到其他版本时，直接选择 **「请勿卸载」→「下一步」** 覆盖即可自动修正系统版本号记录），本机全部存量专注记录、标签、待办及桌面/NAS 连接配置均保存在独立数据目录（`%APPDATA%/com.timebook.desktop/`），升级后自动无损兼容数据结构（存量二级标签默认保持启用），无需重新配置。
   - **免安装便携版**：也可以直接双击运行单文件便携程序 `Timebook_0.2.1_x64-portable.exe`（或 `timebook-desktop.exe`）。
   - *小提示*：本软件为个人开源项目，未购买商业代码签名证书；首次双击若弹出 Windows 安全提示框，点击 **「更多信息」→「仍要运行」** 即可正常打开。
2. **开箱即用**：
   - 首次打开后，**无需填写任何服务器地址或口令**，软件会自动初始化「工作、学习、游戏、锻炼」四个默认模块，直接进入「今日」主界面。
   - 顶部五栏主导航分别为 **「今日 · 日历 · 历史 · 统计 · 标签」**，向下滚动长页面时顶部导航栏常驻吸顶不移走；其中「历史」视图支持按时间预设、自选日期、一二级标签和关键词快速检索与行内/批量整理全部历史记录；「今日」时间横条默认展示 `8–24` 点高密度白天视角，遇早起或凌晨加班记录时自动向左展开；「今日」与「全部未完成」待办列表按截止日期由近到远排序（无截止日期排最后）；「标签」页支持对不再使用的二级事项一键无损停用（不影响历史记录与统计），并可在「已停用」列表中随时查看与重新启用。
   - 界面右上角显示青绿色圆点 **「本机已保存 · 单机模式」**，代表您的所有时间记录、待办和标签都已安全保存在本机。

## 二、日常高频快捷操作（四大桌面部件）

### 1. 置顶灵动胶囊悬浮小窗
- 主窗口打开或缩入托盘时，桌面上会有一条紧凑的**置顶灵动胶囊小窗**（默认白底风格，按住非按钮区域可自由拖拽停放到屏幕任意角落，下次启动会自动记住位置）。
- **平时不打扰**：有计时进行时只显示首条记录的呼吸色点、名称、并行条数徽标（如 `+1`）与每秒走秒；空闲时仅显示「当前空闲 · `+ 开始专注`」。
- **鼠标移入展开**：把鼠标悬停到胶囊上，小窗会平滑展开，显示全部进行中的专注计时与一键 **「结束」** 按钮，以及 **「+ 新建专注」** 和 **「主界面」** 快捷按钮；移出鼠标即自动收回窄胶囊。
- **个性外观与自动隐身**：在主窗口右上角点「设置齿轮」，可将小窗切换为 **「墨色深底」**（浮在白底文档上边界更清晰），也可勾选 **「无进行中计时时自动隐藏小窗」**。

### 2. 右下角系统托盘右键菜单
- 点击主窗口右上角 `×` 按钮时，软件默认**缩入 Windows 右下角系统托盘**继续后台计时，不会中断当前任何专注记录。
- 左键单击托盘图标可随时唤回主窗口。
- 右键点击托盘图标，可在弹出菜单中直接操作：
  - 查看当前进行中条数，并一键 **「结束」** 某条计时或 **「结束全部进行中计时」**；
  - 在 **「快速开始最近常用」** 列表里直接点选最近常用的前 5 个事项，**不用打开任何窗口即可秒开计时**；
  - 切换悬浮小窗显示/隐藏，或选择 **「彻底退出时间簿」**。

### 3. 全局快捷键极速呼出（默认 `Ctrl + Alt + T`）
- 无论您正在使用浏览器、文档还是代码编辑器，按下 **`Ctrl + Alt + T`**，屏幕正上方会弹出极简的 **「极速开始专注」** 呼出框并自动聚焦输入框。
- 输入正在做的具体内容（可留空），点击常用事项标签（或保留「稍后再选」），直接按 **`Enter` 回车**立即开始计时并自动收起呼出框、把键盘焦点还给原来的软件；按 **`Esc`** 可随时取消而不产生任何多余记录。
- 如该快捷键与其他软件冲突，可在设置的 **「桌面版与数据同步」** 中修改为其他组合键（例如 `CommandOrControl+Shift+T`）。

## 三、单机防丢与本地自动备份说明

为防止网页缓存清理导致记录丢失，时间簿桌面版在每次数据变更时都会提供**双重本机保护**：

1. **实时原生文件落盘**：所有数据除了保存在应用内数据库外，同时实时原子写入系统应用数据目录（`%APPDATA%/com.timebook.desktop/timebook-local.json`）。即使内置浏览器缓存被清理，下次打开也会自动从该文件无损恢复全部记录。
2. **每日自动备份快照**：软件每天首次保存或启动时，会自动在您的个人「文档」下的 `TimebookBackups` 文件夹生成按日期命名的快照文件（如 `timebook-local-2026-11-19.json`），默认自动保留最近 30 份（同日后续频繁计时仅原子更新主快照文件，避免重复写盘卡顿）。
   - 您可以在设置中随时修改备份目录，或点击 **「立即备份到本地」** 手动刷新当日最新快照，也可以点击 **「导出全量 JSON / 导出明细 CSV」** 保存到任意位置。

## 四、未来接入绿联 NAS / Docker 服务（单机数据无损合并）

当您在家庭绿联 NAS 或服务器上部署好时间簿服务端容器（参考 [绿联 NAS 部署指南](绿联NAS部署指南.md)）后，无需担心单机期间积攒的数据丢失或与服务端默认模块冲突：

1. 打开桌面端右上角 **「设置齿轮」**，找到顶部的 **「桌面版与数据同步」** 卡片；
2. 填入服务端地址（例如局域网地址 `http://您的NAS地址:3210` 或 Tailscale 地址 `https://您的设备名.ts.net`）以及访问口令；
3. 点击 **「连接并同步」**，桌面端会自动完成无损合并：
   - **默认模块智能去重**：单机期间的「工作 / 学习 / 游戏 / 锻炼」与服务端同名模块自动对齐复用，**不会产生重复的默认模块**；
   - **记录、待办与自定义事项完整上传**：单机新建的模块、事项标签、全部专注记录（包括正在进行的计时）以及待办均会完整同步至服务端数据库；
4. 合并完成后，右上角状态胶囊会切换为 **「数据已同步 · 远程服务」**，从此电脑与手机端即可实时双向同步。如果外出断网，界面会温和提示橙色 **「连接断开 · N 条待保存」**，您可继续照常计时，联网后会自动补传。
