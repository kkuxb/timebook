# 时间簿 · 设计规范

> 和原型保持一致。开发时请把下面的值写成 CSS 变量 / 主题常量，不要在组件里散落写死。

## 1. 原则

- **平面、克制、干净**：白底卡片 + 浅灰背景，不用玻璃、渐变晕染、大面积高饱和色块。
- **每种颜色只负责一件事**（见下表）。新增元素时先问"它属于哪一类"，而不是"它用什么颜色好看"。
- **所有可点击的卡片和按钮**，鼠标悬停时都轻轻上浮、离开时归位，保持统一。

## 2. 颜色角色

| 角色 | 用途 | 颜色 |
| --- | --- | --- |
| 主操作（黄） | 每个视图里"最该点"的按钮：开始专注、补记录、保存；品牌点缀（Logo、日期下划线、今天的日期标记） | `#FFD43B`，悬停 `#FFCC1A`，文字用墨色 |
| 墨色 | 正文；选中状态（导航当前页、选中的日期 / 周期）；次要但重要的按钮（结束、添加） | `#111827` |
| 提醒（橙） | 只用于"需要你处理"：空档、断联状态 | 线 `#FFB38A`、底 `#FFF7F1`、字 `#9A3A0A`、强调 `#C2410C` |
| 危险 | 删除 | `#E11D48`（按钮）、`#C8203E`（文字） |
| 数据色 | 只用于模块 / 事项：标签、时间条、图表、计时卡底色 | 见第 3 节 |
| 中性 | 背景、卡片、边框、次要文字 | 见第 4 节 |

## 3. 数据色（模块颜色）

每个颜色有四档：**色**（时间条、图表、圆点）、**浅底**（标签底、计时卡底）、**深字**（浅底上的文字）、**描边**。四个默认模块之外，另有 4 个备选，供新建模块使用。

| key | 名称 | 色 | 浅底 | 深字 | 描边 | 默认用于 |
| --- | --- | --- | --- | --- | --- | --- |
| blue | 蓝 | `#4F7BFF` | `#EDF1FF` | `#2D4FCC` | `#C9D5FF` | 工作 |
| violet | 紫 | `#8B5CF6` | `#F2EDFF` | `#6236D6` | `#DCCDFF` | 学习 |
| teal | 青绿 | `#14B8A6` | `#E6F7F4` | `#0B7F72` | `#B5E9E1` | 游戏 |
| rose | 玫红 | `#F43F5E` | `#FFEDF0` | `#C8203E` | `#FFC9D2` | 锻炼 |
| amber | 琥珀 | `#F59E0B` | `#FEF5E2` | `#9A5800` | — | 备选 |
| sky | 天蓝 | `#0EA5E9` | `#E5F5FD` | `#086A99` | — | 备选 |
| green | 绿 | `#22C55E` | `#E8F8EE` | `#15803D` | — | 备选 |
| pink | 粉 | `#EC4899` | `#FDEDF6` | `#B5186E` | — | 备选 |

- 同一模块下的多个事项在图表里需要区分时，用模块色与白色按 0%、22%、44%、66% 混合得到深浅。
- 未分类记录用灰 `#B8BDC9`。

## 4. 中性色

| 用途 | 颜色 |
| --- | --- |
| 页面背景 | `#F6F7FA` |
| 卡片 | `#FFFFFF`，边框 `#E8EAF1` |
| 分隔线 / 网格线 | `#EEF0F5` |
| 次级按钮底 | `#F2F3F7`，悬停 `#E9EBF2` |
| 输入框底 | `#F5F6FA`，描边 `#E1E4EC`，聚焦时 2px 墨色描边 |
| 计数徽标 | 底 `#EEF0F5`，字 `#4B5263` |
| 文字：主 / 次 / 弱 | `#111827` / `#4B5263`、`#6B7280` / `#9CA3AF` |

## 5. 字体与字号

- 字体：`Plus Jakarta Sans`（英文、数字）+ `Noto Sans SC`（中文）。
- 所有时间、时长数字用等宽数字（`font-variant-numeric: tabular-nums`）。

| 用途 | 字号 / 字重 |
| --- | --- |
| 页面标题（日历、统计、标签） | 34 / 800 |
| 今日日期 | 42 / 800 |
| 计时大数字 | 52 / 800，字距 -0.03em |
| 区块标题（待办、专注） | 22 / 800 |
| 卡片标题 | 18 / 800 |
| 正文 / 列表 | 14–15 / 700 |
| 辅助说明 | 12–13 / 600 |

## 6. 圆角、阴影、间距

- 圆角：卡片 20；弹窗 24；按钮与输入框 12；小按钮 9–10；标签胶囊 999（全圆）；时间条色块 4。
- 卡片阴影：`0 1px 2px rgba(17,24,39,.04), 0 10px 24px -16px rgba(17,24,39,.16)`。
- 悬停阴影：`0 2px 4px rgba(17,24,39,.05), 0 20px 36px -18px rgba(17,24,39,.26)`。
- 主按钮阴影：`inset 0 1px 0 rgba(255,255,255,.55), 0 8px 18px -10px rgba(214,160,0,.9)`。
- 页面左右边距 40（手机 16）；卡片内边距 18–22；卡片间距 14–20。

## 7. 动效

| 动效 | 规格 |
| --- | --- |
| 卡片悬停上浮 | `translateY(-3px)`，0.28s，`cubic-bezier(.2,.8,.2,1)`，同时加深阴影 |
| 按钮悬停上浮 | `translateY(-2px)`，0.22s；按下 `scale(.97)` |
| 列表行悬停 | 背景变 `#F5F6FA` + 上浮 2px |
| 卡片入场 | 透明度 0→1、位移 12px→0，0.5s（用 `translate` 属性，避免和悬停的 `transform` 冲突） |
| 弹窗 | 遮罩淡入 0.2s；弹窗上移 + 轻微放大 0.3s |
| 进行中 | 圆点呼吸（扩散光圈 1.6s 循环）；时间条上进行中的那段有斜纹缓慢流动 |
| 减少动态 | 系统开启"减少动态效果"时关闭全部动画与过渡 |

## 8. 组件清单

按钮（主 / 墨色 / 次级 / 描边 / 图标）、标签胶囊、计数徽标、卡片、分段切换、日期切换器、时间条、记录行、空档行、环形图、堆叠柱状图、弹窗、输入框、时间输入（±15 分钟）、颜色选择、选项卡（删除时的二选一）、同步状态胶囊。具体样式以 `prototype/` 中的源码为准。
