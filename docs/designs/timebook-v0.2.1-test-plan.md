## 一、测试对象与无打扰隔离规程（`qa` 必读）

1. **只测独立发布包，绝不测开发源码目录**：
   - 被测源码发布包：`dev` 交接元数据提供的 `package_path`（`workspace-data/outputs/timebook/v0.2.1-R<轮次>/timebook.zip`），由父级 `qa` 调用 `fde-qa` 技能自带的 `unpack_verify.py` 解压至 `workspace-data/tmp/qa/v0.2.1-R<轮次>/pkg` 得到 `<pkg_dir>`；同时核对 `dev` 交付目录中的 `installers/`。
   - **包内静态必查项（父级 `qa` 先做）**：确认包内不含 `target/`、`.env`（仅保留 `.env.example`）、`*.sqlite*`、本机用户绝对路径、硬编码局域网真实 `IP` 或测试专用后门代码。
2. **统一编译构建与确定性回归（准备阶段单列计时，避免 4 个子智能体重复编译）**：
   - 父级 `qa` 在解压后的 `<pkg_dir>` 内统一执行一次环境准备与确定性测试：
     1. `corepack pnpm install --frozen-lockfile`（或当锁文件按规更新时 `corepack pnpm install` 并核对）；
     2. `corepack pnpm typecheck`；
     3. `corepack pnpm test`（验证 `@timebook/core` 新增待办截止时间排序、`isTagDisabled`、`merge` 单测及 `@timebook/api` 自动补列、停用同步与存量兼容性集成测试 100% 通过）；
     4. `corepack pnpm build`（验证全栈与 `PWA` 构建通过）；
     5. `cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml`；
     6. `corepack pnpm desktop:build`（从纯净发布包源码独立编译生成真实 `0.2.1` `timebook-desktop.exe` 与 `-setup.exe` 安装包，证明发布包自包含可重现构建）。
3. **无打扰隔离盲测规范（严禁污染用户真实数据、严禁抢占桌面焦点！）**：
   - 每个验收场景（`P1`–`P4`）均由父级 `qa` 使用 `invoke_subagent` 启动干净隔离的子智能体盲测，分配独立目录 `workspace-data/tmp/qa/v0.2.1-R<轮次>/cases/<编号>-run1/`；子智能体指令只给业务任务目标、`<pkg_dir>` 路径、独立数据目录、空闲高端口段（`14601`～`14699`）与安全边界，不喂预期答案、不要求其自建复杂取证脚手架。
   - **强制环境隔离**：
     - 启动后端 `@timebook/api` 时，必须传入独立 `DATA_DIR` 与 `127.0.0.1` 空闲高端口（`14601`～`14699`）；
     - 启动真实编译出的 `timebook-desktop.exe` 时，**必须同时设置**环境变量 `TIMEBOOK_DESKTOP_DATA_DIR="<该场景独立目录>/desktop-data"` 与 `WEBVIEW2_USER_DATA_FOLDER="<该场景独立目录>/webview2"`（严禁裸跑污染用户真实 `%APPDATA%\com.timebook.desktop`、真实「文档」备份目录或真实开机自启注册表！）；
     - 测完必须按自有启动进程 `PID` 精准终止，**严禁执行全局 `taskkill /IM timebook-desktop.exe` 或关闭用户本机日常浏览器**。

## 五、副作用与安全授权边界

- **允许的操作**：
  - 在 `workspace-data/tmp/qa/v0.2.1-R<轮次>/` 下解压发布包、编译验证、创建隔离测试数据库/快照与截图；
  - 在 `127.0.0.1` 空闲高端口（`14601`～`14699`）临时运行被测服务与带 `TIMEBOOK_DESKTOP_DATA_DIR` + `WEBVIEW2_USER_DATA_FOLDER` 环境变量隔离的被测桌面进程（测完按 `PID` 精准清理）；
  - 向 `docs/deliveries/timebook-v0.2.1-R<轮次>-test-report.md` 写入七维测试报告，向 `workspace-data/qa/v0.2.1-R<轮次>/metrics.json` 写入实测计量。
- **严禁的操作**：
  - 严禁修改被测包 `<pkg_dir>` 或项目源码目录代码；
  - **严禁在未设置 `TIMEBOOK_DESKTOP_DATA_DIR` 的情况下启动桌面进程触碰用户真实 `%APPDATA%`、真实「文档」目录或真实开机自启注册表**；
  - **严禁执行不按 `PID` 过滤的全局强杀命令（严禁误杀用户自己正在运行的时间簿或日常浏览器）**；
  - 严禁调用任何外部 `Notion` 接口、严禁连接真实家庭 `NAS`、严禁读写 `H:/个人项目/timebook` 以外项目目录。

## 六、通过规则

1. 包内静态安全扫描清白，`pnpm typecheck`、`pnpm test`、`pnpm build` 与 `cargo test` 100% 通过，独立编译成功产出 `v0.2.1` `-setup.exe` 安装包；
2. `P1`–`P4` 四大隔离场景全部满足合格判据，关键视觉截图（吸顶导航、遮罩覆盖、待办双视图排序、标签停用后占比重算、已停用列表弹窗）经父级 `qa` 用 `read_file` 亲眼核验符合 [视觉与动效设计规范](../设计规范.md)；
3. 无“必须修复”级缺陷、未超硬上限且所有测试临时后台进程与端口已按 `PID` 清理释放；
满足全部条件后，`qa` 方可向 `@coordinator [done]` 提交收口。
