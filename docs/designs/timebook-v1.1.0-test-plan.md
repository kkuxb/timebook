## 一、测试对象与无打扰隔离规程（`qa` 必读）

1. **只测独立发布包，绝不测开发源码目录**：
   - 被测源码发布包：`dev` 交接元数据提供的 `package_path`（`workspace-data/outputs/timebook/v1.1.0-R<轮次>/timebook.zip`），用 `unpack_verify.py` 解压至 `workspace-data/tmp/qa/v1.1.0-R<轮次>/pkg` 得到 `<pkg_dir> = .../pkg/timebook`；同时核对 `dev` 附带输出的安装包产物目录 `installers/`。
   - **包内静态必查项（父级 `qa` 先做）**：确认包内不含 `target/`、`.env`（仅保留 `.env.example`）、`*.sqlite*`、本机用户绝对路径、硬编码局域网真实 `IP` 或测试专用后门句。
2. **统一编译构建与确定性回归（准备阶段单列计时，避免 6 个子智能体重复编译 `Rust`）**：
   - 父级 `qa` 在解压后的 `<pkg_dir>` 内统一执行一次：
     1. `corepack pnpm install --frozen-lockfile`
     2. `corepack pnpm test`（验证 `core` 含合并算法、`notion-import`、`api` 含 `Bearer` 令牌回归 100% 通过）
     3. `cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml`（验证 `Rust` 原生存储、自动备份轮转与托盘逻辑单测通过）
     4. `corepack pnpm desktop:build`（从纯净发布包源码独立编译生成真实 `Windows` 可执行文件与 `-setup.exe` 安装包，证明发布包自包含可重现构建！）
3. **无打扰隔离执行规范（严禁弹窗抢占用户日常桌面焦点！）**：
   - 每个验收场景（`D1`–`D6`）均由 `invoke_subagent(TypeName="self", ...)` 启动干净隔离子智能体执行，拥有各自独立的数据目录 `workspace-data/tmp/qa/v1.1.0-R<轮次>/cases/<编号>-run1/`。
   - **强制环境隔离**：启动真实编译出的 `timebook-desktop.exe` 时，**必须**传入环境变量 `TIMEBOOK_DESKTOP_DATA_DIR="<该场景独立目录>/desktop-data"` 并附带 `--minimized` 参数静默后台运行（严禁污染用户真实 `%APPDATA%`、真实「文档」目录与真实 `Windows` 开机自启注册表！严禁弹出抢焦点的前台窗口干扰用户日常工作！）；界面视觉与交互操作通过无头 `Playwright` 连接构建产物及模拟/真实 IPC 桥在后台静默完成截图与断言，每个场景结束前必须彻底终止其启动的所有进程并释放端口。

## 三、受影响范围与最小复测策略

- 一期核心统计切分、空档、重复待办、`Notion` 导入解析逻辑未改，直接通过父级 `qa` 统一运行 `corepack pnpm test` 完成毫秒级确定性回归，无需重跑一期 `A2`–`A5` 浏览器长流程；
- 本次独立盲测聚焦新增的 `D1`–`D6` 桌面双模式、四部件联动与单机转连 `NAS` 合并闭环；修复轮（`R2`/`R3`）仅重跑受代码变更影响的场景，复用未变场景有效证据。

## 五、副作用与安全授权边界

- **允许的操作**：
  - 若 `dev` 尚未安装或需校验，使用当前用户目录下的 `%USERPROFILE%\.cargo\bin` 官方 `Rust` 工具链在 `<pkg_dir>` 内执行隔离编译与测试；
  - 在 `workspace-data/tmp/qa/v1.1.0-R<轮次>/` 下创建隔离测试数据、本地备份快照与截图，在 `127.0.0.1` 空闲高端口（`14300+`）临时启停被测服务与带 `TIMEBOOK_DESKTOP_DATA_DIR` + `--minimized` 的后台进程；
  - 向 `docs/deliveries/timebook-v1.1.0-R<轮次>-test-report.md` 写入七维测试报告。
- **严禁的操作**：
  - 严禁修改被测包 `<pkg_dir>` 或项目源码目录代码；
  - **严禁在未设 `TIMEBOOK_DESKTOP_DATA_DIR` 的情况下裸跑桌面进程污染用户真实 `%APPDATA%`、真实「文档」目录或真实开机启动注册表**；
  - **严禁弹出前台窗口抢占用户日常鼠标键盘焦点，严禁关闭或干扰用户已打开的日常浏览器**；
  - 严禁调用任何 `Notion` 写接口、严禁连接真实绿联 `NAS`、严禁读写 `H:/个人项目/timebook` 以外目录。

## 六、通过规则

1. 包内静态安全扫描清白，`pnpm test` 与 `cargo test` 100% 通过，独立编译成功产出可安装的 `-setup.exe`；
2. `D1`–`D6` 六大隔离场景全部满足合格判据，关键视觉截图（定制顶栏、胶囊小窗紧凑/展开及黑白双皮肤、桌面设置、全局呼出框）经父级 `qa` 用 `read_file` 亲眼核验符合 [设计规范](../设计规范.md)；
3. 无“必须修复”级缺陷、未超硬上限且所有临时后台进程与端口已清理释放；
满足全部条件后，`qa` 方可向 `@coordinator [done]` 提交收口。
