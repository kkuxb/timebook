## 1. 业务合同

- **使用者与触发**：个人单用户在 `Windows 10/11` 电脑日常开机驻留使用；双击安装包即可在未部署任何服务器的电脑上直接单机记录，也可随时在设置中填入家庭绿联 `NAS` 地址与口令切换为多设备实时同步。
- **输入与来源**：
  1. 桌面快捷操作：在置顶灵动胶囊小窗开始/结束专注、在右下角托盘右键菜单一键点选最近常用的 5 个事项开始计时、在任意软件内按全局快捷键（默认 `Ctrl+Alt+T`）呼出极简框回车秒开计时。
  2. 主窗口全功能操作：完整复用一期「今日 / 日历 / 统计 / 标签」四视图与 `Notion CSV` 历史导入导出；新增桌面行为设置与单机/`NAS` 连接模式配置。
- **输出与去向**：
  1. **桌面四部件协同体验**：自定义无边框圆角主窗口（点 `×` 默认缩进托盘不断计时）、可自由拖拽的置顶灵动胶囊小窗（默认白底，支持一键切墨色深底）、系统托盘状态图标与原生快捷菜单、全局快捷键置顶呼出窗。
  2. **本地与远端双模持久化**：单机直用时除浏览器缓存外，实时同步落盘至本机应用目录文件并每日自动在本地备份目录（默认 `文档/TimebookBackups/`）输出 `.json` 备份快照；连接 `NAS` 后通过签名令牌自动同步至 `NAS` `/data/timebook.sqlite`。
  3. **工程交付物**：本机实编通过的 `Windows` 安装包（`-setup.exe`）与便携可执行程序、仓库云端自动打包配置（`.github/workflows/release-desktop.yml`）及纯中文《`Windows` 桌面版使用说明》。
- **完成判据**：
  - 一期原有单测与网页/容器构建保持 100% 回归通过；
  - `Tauri v2` 桌面应用在本机真实编译生成可执行程序与安装包；
  - 单机开箱直用与本地文件双保险备份、主窗缩托盘、灵动胶囊小窗悬停展开与黑白皮肤切换、托盘最近常用菜单、全局快捷键呼出，以及单机积攒数据首次连接本地模拟 `NAS` 后的无损自动合并同步（`D1`–`D6`）全部通过独立测试。
- **质量底线（不可妥协）**：
  1. **单机零配置可用且不怕清缓存**：未配 `NAS` 时絕不弹登录报错拦截；本机数据必须落盘到操作系统应用数据目录真实文件并支持每日自动文件备份，即使 `WebView2` 网页缓存被清理也不会丢失任何记录。
  2. **单机转连 `NAS` 无损合并**：单机使用一段时间后首次配置连接 `NAS` 时，本机积攒记录、待办与自定义事项必须完整合并上传，同名默认模块（工作/学习/游戏/锻炼）自动复用不产生重复模块。
  3. **轻量不扰人**：平时胶囊小窗紧凑置顶不抢焦点，关闭主窗缩入托盘后计时零中断；视觉色彩与圆角严格遵循 [设计规范](../设计规范.md)，严禁破坏一期网页端与手机端体验。
- **本版非目标（明确不做）**：`macOS` / `Linux` 实机安装包验证（仅在云端配置保留结构，本版只做 `Windows`）、`Windows 11` 系统级原生侧边栏小组件面板、多账号同步冲突人工合并器、应用商店付费签名上架（个人自用采用标准本地安装包）。

## 2. 关键设计与交互细则

### 2.1 技术选型与单仓架构复用
- 采用 **`Tauri v2`（`Rust` 原生壳 + 系统内置 `WebView2`）**，在单仓新增 `apps/desktop/` 包，安装包体积控制在约 `5–15 MB` 量级，避免 `Electron` 百兆体积与高内存开销。
- **单一前端代码库**：不复制维护第二套 `React` 页面，桌面端直接加载 `@timebook/web` 构建产物，通过轻量运行时环境检测启用桌面专属标题栏、多窗口协调（主窗 `main` / 悬浮胶囊窗 `widget` / 全局呼出窗 `launcher`）与桌面设置项；普通浏览器与 `NAS` 容器访问时仍保持原网页体验不变。

### 2.2 双模式存储、本地防丢与首次连 `NAS` 合并机制（已确认 `C-08`、`C-11`）
1. **单机直用模式（首次安装默认启用）**：
   - 免口令直接进入主界面，右上角状态胶囊显示青绿色 **「本机已保存 · 单机模式」**；
   - 每次本机数据变更在更新 `IndexedDB` 的同时，通过 `Tauri` 原生文件接口原子写入本机数据目录（默认 `%APPDATA%/com.timebook.desktop/timebook-local.json`，支持通过环境变量 `TIMEBOOK_DESKTOP_DATA_DIR` 覆盖以便隔离测试）；启动时若 `IndexedDB` 为空而本地文件存在，自动无感恢复；
   - 每日自动在本机备份目录（默认 `文档/TimebookBackups/`，可在设置中更改路径或点「立即备份到文件夹」）生成 `timebook-local-YYYY-MM-DD.json`（保留最近 30 份）。
2. **连接绿联 `NAS` 同步模式**：
   - **服务端跨域令牌兼容（`apps/api` 小幅向后兼容增强）**：`POST /api/login` 在种下原有 `Cookie` 的同时返回签名令牌 `token`；鉴权中间件同时接受原 `Cookie` 或 `Authorization: Bearer <token>` 请求头（并支持受控跨域头），使本地桌面程序无论连接 `http://<局域网IP>:3210` 还是 `https://<设备>.ts.net` 均畅通无阻，且对已有网页版与手机 `PWA` 零影响。
   - **首次接入无损合并流程**：在设置中填入 `NAS` 地址与访问口令并点「连接并同步」→ 先拉取远端现有模块/事项表 → 将本机单机期间的同名模块（如「工作」）及同名事项自动对齐映射到远端 `ID`，其余本机新建模块/事项/专注记录/待办组装为幂等变更批次上传至 `NAS`，再执行一次全量游标对齐，右上角切换为 **「数据已同步 · 远程服务」**；断网时自动回退为橙色「连接断开 · N 条待保存」，网络恢复后自动补传。

### 2.3 桌面四大核心部件细则（已按原型确认 `C-10`）
1. **定制无边框主窗口（`main`）**：
   - 顶部紧凑原生拖拽栏：左侧时间簿图标与名称、居中四栏分段导航、右侧「连接状态胶囊 + 设置齿轮 + 悬浮窗显隐按钮 + 最小化 + 关闭 `×`」。
   - 点击 `×` 默认隐藏主窗口至右下角系统托盘（首次隐藏时气泡轻提示，设置内可改为直接退出）；设置抽屉新增「桌面版与同步设置」分区（切换单机/`NAS` 模式、本地备份目录、开机自启、关闭缩托盘、无计时自动隐藏小窗、小窗白底/墨底切换、自定义全局快捷键）。
2. **置顶灵动胶囊悬浮小窗（`widget`）**：
   - 独立置顶无任务栏图标窗口（`alwaysOnTop: true, skipTaskbar: true, decorations: false`），记忆上次拖拽停放的屏幕位置。
   - **平时紧凑态**：仅高约 `44px`、宽约 `276px`，展示首条进行中计时的呼吸模块色点、事项与具体内容标题、多条并行计数徽标（如 `+1`）及等宽每秒读数；无进行中计时时，若未勾「自动隐藏」则展示紧凑「当前空闲 · `+ 开始专注`」胶囊，勾选则自动隐藏窗口（一旦从任何入口开始计时自动重新浮现）。
   - **鼠标悬停展开态**：鼠标移入小窗区域时，窗口平滑扩展高度，展开全部进行中计时行（每行带一键「结束」按钮）及底部「`+ 新建专注`」「`主界面`」按钮；鼠标移出后自动收回紧凑窄胶囊，最大限度避免遮挡底层办公软件。
   - **外观双皮肤**：默认采用与主界面一致的**白底干净风格**，支持在桌面设置中一键切换为**墨色深底风格**（深色半透明墨底配亮白字，适合长时间浮在纯白文档上区分边界）。
3. **右下角系统托盘图标与快捷菜单（`Tray`）**：
   - 托盘图标悬停气泡实时显示进行中条数（如 `时间簿 · 2 个专注进行中`）；左键单击显示/前置主窗口。
   - 右键原生菜单包含：① 当前进行中计时快捷「结束」项（最多列前 3 条 +「结束全部进行中计时」）；② **「一键开始最近常用事项」**（按最近使用时间自动提取前 5 个未删事项，点击无需打开窗口直接开始计时）；③ `显示 / 隐藏悬浮小窗`；④ `打开时间簿主窗口`；⑤ `彻底退出时间簿`。
4. **全局快捷键极速呼出窗（`launcher`）**：
   - 默认注册系统全局快捷键 `Ctrl+Alt+T`（若被其他软件占用可在桌面设置中修改并给出温和提示）。
   - 按下后在屏幕正中上方置顶弹出轻量呼出框并自动聚焦标题输入框：支持输入可选具体内容、点选常用事项标签（或「稍后再选」），按 `Enter` 立即创建计时并自动收起窗口、归还焦点，按 `Esc` 或失焦关闭。

## 3. 风险、工具链前置与预算

- **本机编译工具链准备（已获 `C-09` 授权）**：开发机已有 `Visual Studio` 目录，尚未安装 `Rust`；实施首步将通过官方 `rustup-init` 在当前用户目录静默安装 `Rust stable (x86_64-pc-windows-msvc)` 工具链用于本地编译与打包验证，不修改系统无关配置。
- **产品运行时模型消耗**：**`0 Token`**（零外部大模型请求）。
- **资源与性能预算**：桌面端空闲/单计时状态下常驻安装包体积 `< 20 MB`，多窗口状态同步延迟 `< 200ms`。
- **研发与独立 `QA` 预算**：初始 3 轮修复循环已执行完毕；2026-11-19 用户本机安装实操发现主窗口卡「正在加载时间簿…」并明确要求检查原因并修复，追加 1 轮定向根因修复（`v1.1.0-R4`，历史 3 轮记录保留不清零），具体根因、原生与前端双端修复及覆盖升级验证规程见 **[v1.1.0-R4 启动卡加载页根因与定向修复补充简报](timebook-v1.1.0-R4-hotfix-supplement.md)**；单验收场景隔离子智能体盲测硬上限 `900 秒`。
