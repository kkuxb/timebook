## 一、测试对象与无打扰隔离规程（`qa` 必读）

1. **只测独立发布包，绝不测开发源码目录**：
   - 被测源码发布包：`dev` 交接元数据提供的 `package_path`（`workspace-data/outputs/timebook/v0.2.0-R<轮次>/timebook.zip`），由父级 `qa` 调用 `fde-qa` 技能自带的 `unpack_verify.py` 解压至 `workspace-data/tmp/qa/v0.2.0-R<轮次>/pkg` 得到 `<pkg_dir> = .../pkg/timebook`；同时核对 `dev` 输出目录中的 `installers/`。
   - **包内静态必查项（父级 `qa` 先做）**：确认包内已彻底不存在 `tools/notion-import/` 目录，且不含 `target/`、`.env`（仅保留 `.env.example`）、`*.sqlite*`、本机用户绝对路径、硬编码局域网真实 `IP` 或测试专用后门代码。
2. **统一编译构建与确定性回归（准备阶段单列计时，避免 6 个子智能体重复编译 `Rust`）**：
   - 父级 `qa` 在解压后的 `<pkg_dir>` 内统一执行一次环境准备与确定性测试：
     1. `corepack pnpm install --frozen-lockfile`（若锁文件已更新则执行 `corepack pnpm install` 并核对一致性）；
     2. `corepack pnpm test`（验证 `@timebook/core` 新增的历史筛选/自适应时间轴/`CSV` 纯函数单测及 `@timebook/api` 回归单测 100% 通过）；
     3. `corepack pnpm build`（验证核心、服务端与网页版 `PWA` 静态资源构建 100% 通过）；
     4. `cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml`（验证 `Rust` 原生存储、每日备份去重与托盘单测通过）；
     5. `corepack pnpm desktop:build`（从纯净发布包源码独立编译生成真实 `v0.2.0` `timebook-desktop.exe` 与 `-setup.exe` 安装包，证明发布包自包含可重现构建）。
3. **无打扰隔离盲测规范（严禁污染用户真实数据、严禁抢占桌面焦点！）**：
   - 每个验收场景（`V1`–`V6`）均由父级 `qa` 使用 `invoke_subagent` 启动干净隔离的子智能体盲测，分配独立目录 `workspace-data/tmp/qa/v0.2.0-R<轮次>/cases/<编号>-run1/`；子智能体指令只给业务任务目标、`<pkg_dir>` 路径、独立数据目录、空闲高端口段与安全边界，不直接喂预期答案。
   - **强制环境隔离**：
     - 启动后端 `@timebook/api` 时，必须传入独立 `DATA_DIR` 与 `127.0.0.1` 空闲高端口（如 `14501`～`14599`）；
     - 启动真实编译出的 `timebook-desktop.exe` 时，**必须同时设置**环境变量 `TIMEBOOK_DESKTOP_DATA_DIR="<该场景独立目录>/desktop-data"` 与 `WEBVIEW2_USER_DATA_FOLDER="<该场景独立目录>/webview2"`（严禁裸跑污染用户真实 `%APPDATA%\com.timebook.desktop`、真实「文档」备份目录或真实开机自启注册表！）；
     - 通过 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS="--remote-debugging-port=<独立端口>"` 连接真实 `Tauri WebView2` 时，可将初始 `desktop-config.json` 的 `widgetPosition` 设在屏幕边缘角落并在验证截图完成后**立即按自有进程 `PID` 精准终止**（严禁执行全局 `taskkill /IM timebook-desktop.exe` 或关闭用户本机可能正在日常使用的浏览器/程序！）。

## 三、受影响范围与最小复测策略

- 一期核心统计周期汇总、日历拖拽创建、重复待办推进逻辑未发生业务规则变更，直接通过父级 `qa` 统一运行 `corepack pnpm test` 完成毫秒级确定性回归；
- 独立盲测聚焦本次 `v0.2.0` 全部四项核心变更与升级兼容性（`V1`–`V6`）；若触发修复轮（`R2`/`R3`），仅重跑受代码改动影响的场景，复用未变场景已通过证据。

| 指标 | 目标值 | 硬上限 | 计量口径与说明 |

## 五、副作用与安全授权边界

- **允许的操作**：
  - 在 `workspace-data/tmp/qa/v0.2.0-R<轮次>/` 下解压发布包、编译验证、创建隔离测试数据库/快照与截图；
  - 在 `127.0.0.1` 空闲高端口（`14500+`）临时运行被测服务与带 `TIMEBOOK_DESKTOP_DATA_DIR` + `WEBVIEW2_USER_DATA_FOLDER` 环境变量隔离的被测桌面进程（测完按 `PID` 精准清理）；
  - 向 `docs/deliveries/timebook-v0.2.0-R<轮次>-test-report.md` 写入七维测试报告，向 `workspace-data/qa/v0.2.0-R<轮次>/metrics.json` 写入实测计量。
- **严禁的操作**：
  - 严禁修改被测包 `<pkg_dir>` 或项目源码目录代码；
  - **严禁在未设置 `TIMEBOOK_DESKTOP_DATA_DIR` 的情况下启动桌面进程触碰用户真实 `%APPDATA%`、真实「文档」目录或真实开机自启注册表**；
  - **严禁执行不按 `PID` 过滤的全局强杀命令（如严禁误杀用户自己正在运行的时间簿或日常浏览器）**；
  - 严禁调用任何外部 `Notion` 接口、严禁连接真实家庭 `NAS`、严禁读写 `H:/个人项目/timebook` 以外项目目录。
